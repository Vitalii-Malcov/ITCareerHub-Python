# Итоговая структура

## Исключение
- **DoorBlockedError** — выбрасывается при попытке доступа к заблокированной двери

## Класс Door

### Атрибуты
- `code` — текущий код доступа
- `failed_attempts` — счётчик неудачных попыток
- `max_attempts` — максимальное количество попыток
- `block_duration` — длительность блокировки
- `block_until` — время окончания блокировки

### Методы
- `__init__(code, max_attempts=3, block_minutes=15.0)` — инициализация двери
- `unlock(code)` — попытка открыть дверь
- `change_code(old_code, new_code)` — смена кода
- `is_valid_code(code)` — проверка правильности кода
- `is_blocked()` — проверка, заблокирована ли дверь
- `remaining_block_time()` — оставшееся время блокировки
- `check_block()` — проверка и установка блокировки
- `handle_failed_attempt()` — обработка неудачной попытки
- `reset_attempts()` — сброс счётчика попыток


## Логика работы

Краткое пояснение схемы:  
* При создании двери задаётся код и параметры блокировки.
* Есть 2 опции работы с дверью (если она не заблокирована):
  * `unlock` - открыть (ввести правильный код)
  * `change_code` - изменить код (но сначала ввести правильный старый код)
* Любой вызов `unlock` или `change_code` сначала проверяет, не заблокирована ли дверь.
  * Если заблокирована — сразу выбрасывается `DoorBlockedError`.
  * Если дверь свободна:
    * при `unlock` проверяется введённый код;
    * при `change_code` проверяется старый код.

* Правильный код → успех + сброс счётчика попыток.

* Неправильный код → отказ + увеличение счётчика неудач.
* Если счётчик попыток достиг максимума — дверь блокируется на заданное время.
